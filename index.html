Whose model runs behind the smart tools

When an MCP tool runs the vendor's model, your question and often your rows reach that model as well as your client's. Counts cover tools reachable over MCP, as documented on 2 November 2026.

"Vendor model, not named" means the docs describe an AI tool without naming the provider. Ask before you route regulated data through it. "Vendor menu" means several providers are on offer and either you or the vendor picks; check which one your tenant uses.

How the second LLM is billed

The MCP server is usually free. Plain tools cost compute; smart tools add an AI charge, and your client's tokens don't go away.

What your model provider sees

Every byte a tool returns goes into your client's context and on to its provider. A smart tool doesn't change that: its answer still comes back to your client, and the platform's model sees the data on the way.

Q: How many active customers in Chennai?
→ list_tables, describe_table dim_cust
→ SELECT * FROM dim_cust LIMIT 20
names, phones, emails now in context
→ SELECT DISTINCT cust_flg_3 …
guessing what "active" means
→ invents a definition; finance disagrees
Where the platform's model runs matters too. Snowflake Cortex routes to other regions when CORTEX_ENABLED_CROSS_REGION allows it. Fabric data agents need cross-geo processing switched on in regions without Azure OpenAI. Check Google's conversational analytics endpoints against your residency rules.

Controls, in the order they pay off

  1. Metadata before rowsWrite column comments and expose descriptions, glossary terms and metric definitions as tools, so the agent never samples a column to learn what it means.
  2. Profile inside the warehouseA profile_column tool returns counts, null share, min, max and masked top values. The shape without the records.
  3. Query through the semantic layerMetric queries return one aggregate row, not twenty customer records.
  4. Enforce in the databaseA read-only role for the MCP connection with masking and row access policies. A prompt can be ignored; a masking policy can't.
  5. Cap what comes backRow limits, byte limits and timeouts on the server or role, not left to the agent.
  6. Contract and routingZero data retention terms with your client's provider, or route sensitive schemas to a model you host.

What counts as a second LLM

A tool on the vendor's MCP server that sends your question to a model the vendor runs or you configure on the vendor side. AI features that exist only in the product's own UI are marked separately, because a coding agent never calls them.
